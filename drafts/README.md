# drafts/ — what is in here, and how it relates

_Organised 31 Oct 2026 into one folder per topic. Code comments that name a design
source were updated in the same change — if you move a file, grep for its path._

**Status key:** ✅ BUILT — the live code was made from it (it is the design source) ·
📚 REFERENCE — research, briefs, specs · 🧪 SAMPLE — real-world forms/data used to build
or test a feature · 📸 EVIDENCE — a screenshot · ❓ LOOSE — no code uses it yet.

🔒 = git-ignored on purpose (personal data or third-party documents; the repo is public).

```
drafts/
├── bout-video/            watching, reviewing, sharing a match + the mat camera
├── scoreboards/           scoring consoles and hall screens
├── events/                the draw, entry cards, public event pages
├── federations/           federation dashboard + UX brief
├── entry-forms-and-data/  printed entry forms, division sheets, sample entry lists
├── clubs-and-trainers/    club & trainer public pages + club-admin UX review
├── certificates/          printables designer spec + certificates package drop
├── research/              competitor studies (Smoothcomp, Martialytics)
└── tools/                 side tools (ID-card reader kit)
```
